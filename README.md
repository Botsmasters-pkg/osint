# Telegram Starter Bot

A Telegram bot built with Python 3 and `python-telegram-bot` v21.

## Quick Setup

1. **Install requirements:**
   ```powershell
   cd C:\Users\pawan\Downloads\user_bots
   pip install -r requirements.txt
   ```

2. **Add Bot Token:**
   Open `.env` and set:
   ```env
   TELEGRAM_BOT_TOKEN=your_token_from_botfather
   ```

3. **Run the bot:**
   ```powershell
   python bot.py
   ```
